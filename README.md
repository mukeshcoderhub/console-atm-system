# Console ATM System

A simple console-based ATM system made with **C programming**.
This project allows users to log in, check their balance, deposit money, withdraw money, and view account details.

## Features

* Account number login
* PIN verification
* Check balance
* Deposit money
* Withdraw money
* View account details
* Multiple users

## How to Use

1. Download or clone this repository.
2. Open the project in VS Code or any C-supported IDE.
3. Compile and run the C file.
4. Enter an account number and PIN from the `users` array.
5. Select an option from the ATM menu.
